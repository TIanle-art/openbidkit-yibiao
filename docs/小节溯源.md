# 小节来源与参考

入口：`标书生成 → 生成技术方案 / 已有方案扩写 → 正文 → 选择小节 → 来源与参考`。

| 页签 | 查看内容 |
|---|---|
| 招标依据 | 已保存的要求引用、章节、引用页码及依据摘录 |
| 内容参考 | 生成参考快照、知识库文件、原始块、原方案和全局事实 |
| 图片来源 | 正文实际图片、来源文件及原章节；点击图片放大 |

状态：`已记录 / 待确认 / 缺依据 / 版本变化 / 待定位 / 生成图`。

**已记录只表示存在来源记录，不表示材料有效或本项目适用。** 引用页码须核原件；原始块编号及图片序号不当作物理页码。

新模板填写保存依据摘录、条目/文档哈希及正文哈希；新正文编排保存证据包，完成时绑定本轮处理的正文版本。手工编辑正文或来源变化后显示提示。目录排序保留既有计划；目录修改按既有规则使受影响计划失效。

旧正文：仅展示已保存的参考及目录关联候选；缺记录显示缺依据。全局事实尚无原始文件证据时显示待定位。原方案片段 ID、标题及哈希分别去重，不能按下标强行配对。

补证据：可选择原件并保存 PDF 物理页预览；也可对唯一文本引用执行“补定位”。补充证据先标为待确认，查看原件后人工确认。正文或来源变化时提示重新核对，旧正文版本不能确认。
