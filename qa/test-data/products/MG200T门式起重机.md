# MG200T 双梁门式起重机 产品技术说明

> **SYNTHETIC TEST DATA — NOT REAL**（合成测试数据，非真实产品参数）

## 1. 型号与总体参数
- 型号：MG200T（100+100/10+10）-39m
- 起重量：额定 200t，单小车跨中可吊 100t，副钩 10t
- 跨度：39m
- 起升高度：12m（主钩），副钩另行布置
- 工作级别：A4
- 结构形式：双梁桁架式门架，Q235-B/Q355B 主要承载构件

## 2. 起升机构
- 主起升电机：YZP 变频电机，30kW（合成）
- 副起升：电动葫芦，13kW
- 起升速度：主钩 1.5m/min，副钩 7m/min
- 制动器：液压推杆式制动器，双制动冗余（合成）
- 钢丝绳：采用 6×36WS + IWR 钢丝绳，安全系数符合 GB/T 14406（合成）

## 3. 运行机构
- 大车运行：4×11kW YZP 变频电机，速度 2.0–20m/min（合成）
- 小车运行：2×3kW，速度 0–15m/min
- 减速器：三合一模块硬齿面减速器，采用宁波东力/国茂/泰隆等（合成）
- 车轮：锻造 65Mn，轨型 QU100

## 4. 电气与控制
- 供电：三相交流 380V/50Hz，电缆导电
- 变频：大车、小车全变频（安川/台达/三菱等）
- 控制：PLC + 空操 + 无线遥控
- 防护等级：IP54，绝缘等级 F

## 5. 安全保护
- 起升双限位（上升极限限位器 + 重锤限位开关 + 下降限位）
- 超载限制器、力矩限制（合成）
- 大车防撞装置、电动液压夹轮器、防风联动铁鞋、防台风地锚、缆风绳拉环
- 视频监控系统、声光报警

## 6. 表面处理
- 冲砂除锈 Sa2.5，环氧富锌底漆 2 道 40μm、环氧云铁中间漆 1 道 70μm、聚氨酯面漆 2 道 40μm
