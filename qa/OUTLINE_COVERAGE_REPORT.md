## Coverage 算法和保护

- ID 精确命中：`covered`
- 旧目录无 ID：使用标题/描述/关键词相似度分为 `covered` / `partial` / `missing`
- 得分：`(covered + 0.5 * partial) / total`
- <90%：最多自动修正一次
- 修正后 <80%：目录任务失败，不进入正文生成
